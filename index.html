Missão Aviator

  • Hold anywhere on the screen to climb
  • Release to descend
  • Space or ↑ on desktop
Prototype — not a live page

A landing page variant where the visitor has to fly a plane through an airfield to the Rivalo logo before a promo code unlocks. This page is the game on its own, without the landing page around it, so it is easy to try and comment on.

The course is identical for every player — no randomness, so the result depends only on how you fly. Crashing costs nothing and restarts instantly.
